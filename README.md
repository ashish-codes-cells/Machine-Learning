# K-Means Clustering

This project contains my implementation and practice of K-Means Clustering using Python Scikit-learn.

## What I Learned

- K-Means Clustering
- fit-predict()
- Elbow Method
- WCSS (Within-Cluster Sum of Square)
- Silhouette Score
- Choosing the optimal numbers of clusters

## Datasets

For this project I used the `make_blob()` function from Scikit-learn to generate synthetic clustered data.

- Samples: 1000
- Features: 2
- Centers: 4

## Libraries Used

- Python
- Scikit-learn
- Seaborn

## Notebook

The implementation was created and practiced in Google Colab.
